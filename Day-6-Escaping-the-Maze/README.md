# Day 6 - Escaping the Maze

This is the final project from Day 6 of my Python learning journey.

## About

This project was built and tested using Reeborg's World.

The goal is to guide Reeborg through a maze and reach the goal.

## Concepts Used

- Functions
- While loops
- If / elif / else
- Boolean conditions
- `move()`
- `turn_left()`
- `front_is_clear()`
- `right_is_clear()`
- `at_goal()`

## Algorithm

The program uses the right-hand rule to navigate through the maze.

1. Move forward while the path is clear.
2. Check if the right side is clear.
3. If the right side is clear, turn right and move.
4. Otherwise, if the front is clear, move forward.
5. Otherwise, turn left.
6. Continue until Reeborg reaches the goal.
